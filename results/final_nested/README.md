# Final repeated nested-CV results

This directory contains the primary analysis requested in the preliminary feedback.

## Protocol

- 569 records, sorted by ID before split generation.
- Ten repeats of stratified five-fold outer CV, with seeds 707–716.
- Five-fold inner CV inside each outer-training set for model selection.
- Identical outer validation folds for every model.
- Scaling and SVM sigmoid calibration fitted only on training data.
- The 95% sensitivity threshold selected from inner out-of-fold predictions and then applied unchanged to the outer validation fold.
- Repeat-level metrics pool all five outer folds, giving exactly one prediction per record per model per repeat.

The Linear and RBF SVM predictions were imported from the previously completed `asher/svm-analysis` workflow only after confirming exact outer-fold ID agreement. All other model predictions were generated by `src/final_analysis.py`.

## Main findings

- RBF SVM mean AUROC: 0.9943.
- Stable ridge logistic mean AUROC: 0.9936.
- Mean paired RBF-minus-ridge AUROC difference: +0.0007; repeat range -0.0003 to +0.0014.
- The numerical RBF advantage is too small and inconsistent to support a strong superiority claim.
- Unpenalized logistic regression produced extremely large coefficients and nearly all-zero/all-one probabilities, consistent with separation. It is retained as an unstable comparator; ridge logistic (`C=1`) is the prespecified stable fallback.
- In the Elastic Net feature-set analysis, all features and worst-only features had similar AUROC (0.9910 versus 0.9906). Worst-only features had a lower Brier score and less repeat-to-repeat variation. SE-only features were clearly weaker.

## Files

- `model_summary.csv`: mean, SD, minimum, and maximum by model.
- `repeat_metrics.csv`: one row per model and repeat.
- `paired_difference_summary_vs_stable_logistic.csv`: paired repeat contrasts against ridge logistic.
- `outer_predictions_all_models.csv`: complete outer predictions with fold-specific locked thresholds.
- `learning_curve_summary.csv`: training sizes 50, 100, 200, and 455.
- `feature_set_summary.csv`: mean, SE, worst, and all-feature comparison.
- `figures/`: presentation-ready summaries.

Repeated folds reuse the same 569 records. Their SD and range describe sensitivity to the split and must not be presented as uncertainty from ten independent datasets.
